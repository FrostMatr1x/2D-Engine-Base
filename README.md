# 2D-Engine
Легковесный 2D-движок на базе **MonoGame/XNA**. Изначально создавался для закрытого игрового проекта, а позже я добавил GUI интерфейс. Включает ECS-подобную структуру, систему ввода, базовый UI и анимации.

> ⚠️ **Статус проекта:** Архив / Не поддерживается.  
> Я закрыл разработку игры, для которой создавался этот движок, и перехожу к новым задачам, но возможный доработки мною кода. Код выложен в открытый доступ как образовательный ресурс или база для ваших собственных экспериментов.

## История
Этот движок начинался как внутренний инструмент для моей 2D игры на **MonoGame/XNA**.
Теперь, когда я закрываю этот проект, я решил не удалять наработки, а поделиться ими.

## Что внутри (Features)
Ядро движка содержит реализованные системы:

*   **Архитектура:** Базовые классы `GameObject` и `Transform`.
*   **Физика и Коллизии:** `PhysicalBody` и `Collider` для обработки столкновений и триггеров.
*   **Анимации:** `EntitiesAnimations` — удобная система управления спрайтами и состояниями анимации.
*   **Ввод (Input):** `InputHelper` — система для обработки нажатий клавиатуры и мыши.
*   **Интерфейс:** `UIElement` — качественная база для создания интерфейсов.
*   **Отладка:** Встроенный `Debug` инструмент.
*   **Камера:** Базовая реализация `Camera` (требует доработки под сложные задачи).

## Что не сделано

*   **UICanvas:** Не реализован. Код при использовании StretchSettings отлично справляется с позиционированием на экране любого разрешения
*   **Контроллер сцены:** В будущем думал его сделать
*   **Система частиц:** Отсутствует.
